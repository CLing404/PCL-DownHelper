### Scope of functionality
⚠️ This project only restores the automatic installation feature of Plain Craft Launcher 2. The modpack installation feature has **not** been restored.

### Implementation & self-verification
⚠️ This project is implemented using DLL injection, which may cause the program to become extremely unstable (optimized in V1.0). It is recommended that you stop using it once your research is complete.

This project does **not** modify any file of Plain Craft Launcher 2 itself — it only modifies process memory.
To verify this, you can compare the SHA-256 value of the executable before and after running.

### Security self-verification
- Compile from source yourself
- Run in a sandbox / virtual machine
- Upload to https://www.virustotal.com to scan the hash
